# Fridgetto

A home for several independent projects. Each one lives in its own folder with its own dependencies, scripts and README.

| Project | What it is | Stack |
| --- | --- | --- |
| [`tungston-ai/`](./tungston-ai) | Marketing website for Protomation.ai, an AI agency, with an interactive water-ripple dot grid hero | Next.js 16, Tailwind CSS 4, GSAP, Lenis |

## Adding a project

Create a new top-level folder, keep everything for that project inside it, and add a row to the table above. Run installs and scripts from inside the project folder (for example `cd tungston-ai && npm install`).
